# ECHO//EARTH

A speculative editorial field archive for disappearing natural soundscapes.

Built with React, TypeScript, and Vite using the Rafa UI/UX Framework: high-contrast editorial typography, quiet technical structure, restrained coral accent, responsive recomposition, and purposeful motion.

## Local development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```
